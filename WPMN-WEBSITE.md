# WPMN and ECF website source

The public ministry website source is in [wpmn-ecf-website](./wpmn-ecf-website). This branch preserves the existing Epignosis streaming app at the repository root.

Site source snapshot: `b7e4ec1a4be56eb2ac1fa2333d53ac80a319643c`.

Live website: https://wpmn-ecf.franciskumi17.chatgpt.site

Hosting: Sites on Cloudflare. This GitHub branch is a source copy, not an automatic deployment connection. The community photograph is also excluded; see the image folder README.

See the website README for editing access, contact handling, and remaining external integrations.
