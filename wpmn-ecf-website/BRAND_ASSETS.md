# Website brand assets

The deployed website uses the official ECF horizontal logo from ECFBrandGuide.pdf, page 11. The code refers to public/images/ecf-horizontal.png and public/images/ecf-avatar.png. These logo files and community photographs are excluded from this public code copy. Add approved assets locally when reconstructing the site. Do not substitute an AI likeness of a member or pastor.

Official colors: Midnight Violet #342758 and Faith Teal #437D7C. Fonts: Inter and Cormorant Garamond.
